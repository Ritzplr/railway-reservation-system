# Railway Reservation System

A console ticket-reservation program in C++ for Indian Railways routes. It takes the boarding and destination stations, works out distance and fare, and lets station data be added and modified.

## Notes

This was written in Turbo C++ style (`conio.h`, `fstream.h`, `gets`), so it builds with an old DOS-era compiler such as Turbo C++ or DOSBox, not with a current GCC or Clang without changes.

## Files

- `Railway Reservation_system.cpp`: the whole program (a `railways` class for station, distance and fare, plus the menu)
